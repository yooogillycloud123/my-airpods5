Filee 1.12.0을 기반으로 만든 독립적인 Windows 오프라인 배포본입니다.

- 한국어 기본 UI, 원형 드래그 변환 메뉴.
- .NET 런타임과 모든 추가 변환 엔진을 사전 포함합니다.
- 업데이트 타이머·수동 업데이트·엔진 다운로드를 차단합니다.
- 앱의 HTTP 클라이언트도 실제 소켓을 만들지 않는 로컬 핸들러로 교체합니다.
- 첫 실행 다운로드 화면을 생략하고 일반 Filee와 설정을 분리합니다.
- Windows에서 배포본 EXE들의 외부 통신을 차단한 상태로 변환을 확인합니다.
- REA 분석 기록, 자동 테스트 결과와 실제 변환 결과는 Actions 검증 아티팩트에 있습니다.

설치형 EXE 또는 전체 무설치 ZIP 중 하나를 사용합니다. 무설치형은 DLL과 engines 폴더를 함께 유지하세요.
검증한 파일과 범위는 `검증결과.json`을 확인하세요. 개별 회사 PC의 드래그 조작과 모든 업무 문서의 배치를 보증하는 것은 아닙니다.
