Filee Offline 1.12.0

1. 설치형: Filee-1.12.0-Offline-Setup.exe를 실행합니다.
   무설치형: ZIP 전체를 풀고 그 안의 Filee.exe를 실행합니다.
   무설치형의 EXE만 따로 옮기면 안 됩니다. DLL과 engines 폴더가 함께 필요합니다.
2. 파일 탐색기에서 파일을 끌면서 Ctrl을 누르고, 원형 메뉴의 원하는 형식에 놓습니다.
   앱의 홈 화면에 파일을 놓는 방법도 사용할 수 있습니다.
3. 변환 결과는 기본적으로 원본 옆에 새 파일로 저장됩니다.
4. 첫 실행부터 인터넷 연결, 별도의 .NET 설치, 추가 엔진 다운로드가 필요하지 않습니다.
   한글 기본 UI, rhwp, 7-Zip, FFmpeg, LibreOffice, Java, H2Orestart, Pandoc, Ghostscript,
   calibre와 실행에 필요한 파일을 배포 폴더에 포함했습니다.
5. 앱 업데이트·엔진 다운로드는 코드에서 껐습니다. 설정을 바꿔도 온라인 업데이트되지 않습니다.
   자체적으로 새 프로그램을 다운로드해 실행하지 않습니다.
6. 일반 Filee와 설정을 분리했습니다. 설정은 %APPDATA%\FileeOffline에 저장됩니다.
   원본 Filee의 기존 설정과 파일은 변경하지 않습니다.

검증 범위는 함께 제공한 검증결과.json에 기록되어 있습니다.
Windows에서 프로그램의 외부 통신을 방화벽으로 막고 실제 변환한 결과입니다.
REA의 DLL 정적 분석 기록과 실제 실행 검증은 서로 구분해 보관했습니다.
회사 PC에서의 마우스 드래그 조작과 모든 개별 업무 문서의 배치를 검증한 것은 아닙니다.
특수 글꼴, 복잡한 한글/Office 문서, 스캔 PDF의 OCR에는 원본 엔진의 한계가 적용됩니다.
